# Asma-ul-Husna – 99 Names of Allah

A simple and interactive website dedicated to the 99 Beautiful Names of Allah, designed to make learning their meanings a peaceful and enjoyable experience.

## Features

- 99 Names of Allah in Arabic
- English and Urdu meanings
- Audio recitation features
- Dark and light mode
- Responsive design
- Simple and user-friendly interface

## Technologies Used

- HTML5
- CSS3
- JavaScript

## About the Project

This project was created to provide an accessible and engaging way to explore the 99 Names of Allah, combining a clean design with useful learning features.
